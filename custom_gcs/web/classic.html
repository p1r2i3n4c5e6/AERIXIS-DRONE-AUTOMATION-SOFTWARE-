    How the Behavior Tree is Sent over Radio Telemetry

    Standard radio modems (SiK, Holybro, RFD900) operate over low-bandwidth serial lines (57,600 baud). High-volume ROS 2 traffic cannot travel directly through the air.

    1
    Design on GCS Laptop

    Plan mission in 3D studio, setting altitudes, coordinates, and speeds.

    2
    Upload XML to the onboard executor

    The fleet service transfers the XML over an authenticated connection and verifies its checksum onboard.

    3
    Onboard Assembly on RPi 5

    The onboard mission manager stores and validates the exact XML revision. Uploading does not start flight.

    4
    AERIXIS Engine Executes

    An explicit start request runs the validated tree onboard. Actual node states and errors return to the GCS.
